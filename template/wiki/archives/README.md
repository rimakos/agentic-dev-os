# archives

Roll-off graveyard. Never delete, only move.

When `wiki/log.md` passes ~600 lines or a calendar month closes, move that
month's oldest entries into `archives/log-YYYY-MM.md` and keep the newest in the
live file. Same rule for any wiki page that outgrows one screen.

The live files stay a usable timeline; the full history lives here, greppable.
