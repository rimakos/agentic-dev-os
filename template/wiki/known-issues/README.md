# known-issues

Working rules by topic. Each rule lives in one page, with its reason and without the incident
that prompted it. Read the page that matches the work; `/wrap` adds to them when a correction
will apply again.

- [[verification]]: reading code and state, running things, claims, merges.
- [[pr-review]]: reading a PR and verifying findings.
- [[repo-targeting]]: which repo owns a change.

Add a page per recurring topic (dev testing, a fragile subsystem, shared writing) when one grows
past a few rules.
