# Repo targeting

- Confirm which repo owns a change before editing; if it is ambiguous, name the candidate and wait.
  Watch for same-named libraries in different ecosystems (a backend package and a frontend package
  with similar names).
- Endpoints or classes named after another service may still be owned by the backend of record:
  check where the code lives, not what it is called.
- Before a rebase, check the change is not already merged.
